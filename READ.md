# Goa Tourism Website

A beautiful, responsive website showcasing the attractions and culture of Goa, India.

## Features
- Responsive design that works on all devices
- Beautiful image galleries of Goa's beaches
- Information about Goan culture and heritage
- Interactive elements and smooth animations

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Unsplash Images
